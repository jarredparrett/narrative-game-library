# The Sybil's Cave Proof — playable handoff

This folder is the host handoff for a four-player, one-host investigation that
runs about 75 minutes. It contains only the files needed to play: one host
guide, four private role dossiers, and eight shared evidence PDFs.

Everything in the game is fictional game material. Sybil's Cave, Mary Cecilia
Rogers, and Edgar Allan Poe provide the historical frame; the modern
disappearance, characters, proof packet, and tenant account are invented.

## Share this safely

Send `sybils-cave-proof-human-handoff.zip` to the **host only**. The host guide,
other dossiers, and unreleased evidence contain spoilers.

Before play:

1. Read `instructions/host-guide.pdf` privately.
2. Assign the four roles and give each player only their own dossier.
3. Keep all eight evidence files with the host until their release time.
4. Print one copy of each dossier and evidence file, or share the PDFs privately.

## Roles

- Ada Bell — Hoboken historian
- Morgan Voss — paper conservator
- Nora Vale — investigative reporter
- Elias Crane — literary appraiser

The dossiers contain each role's public identity, private knowledge, objective,
opening move, leverage, and disclosure boundary.

## Release order

| Time | Phase | Release |
|---|---|---|
| 0 minutes | Briefing | `01-public-briefing.pdf` and all private dossiers |
| 10 minutes | Provenance | `02-poe-method-note.pdf`, `03-timeline.pdf`, `04-fiber-report.pdf`, and `05-access-log.pdf` |
| 35 minutes | Rescue | `06-tenant-account-abstract.pdf`, `07-voice-message.pdf`, and `08-pump-card.pdf` |
| 60 minutes | Resolution | Ask for the fabricator, Quill's location, and at least one corroborated evidence path |
| 70 minutes | Debrief | Use the truth and historical boundary in the host guide |

If players identify immediate danger—or the session reaches minute 50—release
the pump card and narrate the rescue before continuing the accusation. Safety
does not depend on any player's cooperation.

## Package boundary

The tenant-account PDF is an accessible in-game abstract. It is not represented
as an independently realism-qualified lease. Experiment traces, model reviews,
answer-key research, and rejected artifact Candidates are intentionally absent
from this handoff.

## Integrity

After downloading the folder, verify the exact playable bytes with:

```bash
shasum -a 256 -c SHA256SUMS
```
