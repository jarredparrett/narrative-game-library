# The Winter Observatory — Candidate 6 artifacts

This is the human handoff for The Winter Observatory Candidate 6: a six-player,
one-host murder-mystery game that runs approximately 150 minutes. It includes
the 19 fictional evidence documents, host instructions, and private player
dossiers.

## Easiest way to share

Send `winter-observatory-candidate-6-human-handoff.zip` to the **host only**.
The host then distributes one private dossier to each player and releases the
evidence according to the phase instructions. The ZIP contains:

- `instructions/host-guide.md` — setup, answer key, six-phase sequence, hints,
  and resolution guidance;
- `instructions/players/` — one private dossier for each of the six roles;
- `instructions/clock-primer.md` — the shared in-world calculation guide;
- `instructions/accusation-form.md` — the group’s final finding;
- `documents/` — the 19 individual evidence PDFs;
- `combined-review.pdf` — all 19 documents in one PDF for the host or reviewer;
- `contact-sheet.jpg` — a one-page visual overview; and
- this guide.

## Running the game

1. The host reads `instructions/host-guide.md` before play.
2. Assign the six roles and privately give each player only their dossier.
3. Keep the evidence PDFs with the host and release them in the six phases
   listed in the host guide.
4. Share `instructions/clock-primer.md` when the host guide calls for it.
5. Share `instructions/accusation-form.md` in Phase 5.
6. Do not give players the combined review PDF, contact sheet, other dossiers,
   or host guide: those materials reveal unreleased evidence or the solution.

The role dossiers are the player instructions. Each contains the character’s
public identity, private knowledge, objectives, opening belief, and first move.

## Suggested review prompt

> These are fictional documents from a murder-mystery game set at a private
> American observatory in January 1937. Please review them as physical and
> institutional artifacts. Identify anything that looks modern, synthetic,
> historically implausible, internally inconsistent, or unlike a document that
> would actually have been produced and used. For every issue, name the document
> and quote or describe the exact visible detail. Also identify the strongest
> artifacts and explain why they work.

The review should evaluate the artifacts, not solve the mystery. Every file in
this package can contain spoilers, so the full package should not be sent to
prospective players before the game.
